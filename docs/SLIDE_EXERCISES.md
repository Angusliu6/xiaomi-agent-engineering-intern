## 随堂评分表

每次只用 100 分：机制 25（准确边界）、代码 35（独立实现）、失败诊断 25（可证伪）、评测证据 15（真实结果）。概念解释可以 100% 正确，但如果代码无法运行，模块仍不算毕业。

## 教练追问规则

- 不问“背出定义”，而问“输入/状态/输出/反例/测试”。
- 对有信心但答错的问题，先让学生写一段最小测试，再做总结。
- 评分只依据他亲自解释与提供的证据；自动生成代码的存在不等于个人已掌握。

## 新增审计口试：考官不得先给答案

- 你有两份结果，案例 ID 完全相同，但 gold_doc 和文档内容不同。能否继续做 paired A/B？要求指出工具报什么错。
- 你的模型 API 超时。为什么 `planning_failed` 比 `insufficient_evidence` 更诚实？该错误应否计入“正确拒答率”？
- `hn003` 检索到了 RRF 定义，但问题要求客户流量 P95。你需要怎样标注“文档相关但不蕴含答案”？
- 你如何设计一个 *有证据缺口追踪*、但不泄漏 holdout gold 的 Agent 动态检索实验？

验收：每题必须提交预测、`traceqa` 实际输出、失败归因和一段可复现的测试，不能只说概念。
